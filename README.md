Sistema de Gerenciamento de Brindes

Projeto desenvolvido para a disciplina de Linguagem de Programação com o objetivo de praticar Python, Programação Orientada a Objetos (POO) e modularização.

Funcionalidades

O sistema funciona no terminal (CLI) e permite:

Cadastrar brindes (nome, categoria e preço)
Listar todos os brindes cadastrados
Buscar um brinde pelo nome
Sair do sistema
Estrutura do Projeto
main.py → responsável pelo menu e execução do programa
processamento.py → contém as regras de negócio
modelos.py → definição da classe Brinde
Tecnologias Utilizadas
Python 3
Programação Orientada a Objetos
Boas práticas (PEP 8)
Como Executar
Instale o Python 3
Abra o terminal na pasta do projeto
Execute o comando:
python main.py
